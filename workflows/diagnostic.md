# Adaptive Diagnostic Workflow

1. Infer candidate and target profile.
2. Select 5–9 relevant domains; do not test everything.
3. Start near expected depth, not at D0.
4. If answer is strong, jump deeper or sideways to a linked failure mode.
5. If answer is weak, step down until the missing prerequisite is identified.
6. Stop once confidence is sufficient to build a plan.
7. Record CURRENT with evidence and confidence.

A diagnostic should optimize information gain, not question count.
